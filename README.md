# จันทร์ใจ · CHANJAI

เว็บไพ่ทาโรต์ภาษาไทย เน้นมือถือ โทนม่วงหมึก–ทองแชมเปญ กระจกโปร่ง แสงนุ่ม และแอนิเมชันสับไพ่/พลิกไพ่ รองรับ `prefers-reduced-motion`

## เริ่มพัฒนา

ใช้ Node.js 22.12+ (ทดสอบกับ 24.22.1) และ npm:

```sh
cd /workspace/tarot
npm ci
npm run dev
```

```sh
npm run build        # ตรวจ TypeScript และ build production ไปที่ dist/
npm test             # ทดสอบสำรับ การสุ่ม วันเวลา สตรีค และ storage
npm run test:e2e     # ทดสอบ flow จริงด้วย Chromium
npm run preview     # ตรวจ production build
```

Browser tests ใช้ `/usr/bin/chromium` ใน cloud เครื่องนี้ ถ้าใช้เครื่องอื่นให้กำหนด `CHROMIUM_PATH` เป็นพาธ Chromium ที่ติดตั้งไว้ ระบบไม่ต้องใช้ database, API key หรือ environment secret

## เวอร์ชันฟรีที่ทำงานแล้ว

- ไพ่ประจำวันฟรี 1 ใบ ใช้วันตาม `Asia/Bangkok` เปิดซ้ำได้ใบเดิมภายในเบราว์เซอร์ที่ยังมีข้อมูลอยู่
- สเปรด 1 หรือ 3 ใบ สุ่มไม่ซ้ำด้วย Web Crypto: ความรัก การงาน/การเงิน ภาพรวมชีวิต
- Yes / No แบบชวนคิด: เปิด 1 ใบ พร้อมแนวทางที่ไม่ฟันธงผลลัพธ์
- สำรับ 78 ใบ (22 Major + 56 Minor) ความหมายภาษาไทยแบบตั้งตรง และห้องสมุดไพ่ที่ค้นหา/กรองได้
- เก็บประวัติไม่เกิน 150 ครั้งและคำถามใน `localStorage` พร้อมลบได้โดยยืนยันก่อน
- สตรีคนับจากวันที่เปิดไพ่ประจำวันต่อเนื่อง
- ภาพแชร์ PNG 1080×1440 สำหรับทั้ง 1 และ 3 ใบ ไม่ใส่คำถามส่วนตัวในภาพ ใช้ native file sharing เมื่อเบราว์เซอร์รองรับ และดาวน์โหลดได้เสมอเมื่อสร้างภาพสำเร็จ
- ถ้าพื้นที่จัดเก็บถูกปิดกั้น ยังเปิดไพ่และบันทึกภาพได้ พร้อมแจ้งว่าประวัติไม่ได้บันทึกถาวร
- ฟอนต์และภาพ SVG อยู่ในโปรเจกต์ ไม่เรียก Google Fonts หรือบริการ AI ระหว่างเปิดไพ่

## ใส่ชุดไพ่จริง

ขณะนี้ใช้ภาพ SVG ชั่วคราวที่วาดสำหรับเว็บนี้ **ยังไม่ได้รับไฟล์ไพ่ของผู้ใช้** นำภาพมาใส่ `public/cards/` แล้วจับคู่รหัสใน `public/cards/manifest.json` ดูตัวอย่างใน [คู่มือภาพไพ่](public/cards/README.md) ภาพที่ไม่พบใช้ภาพสำรอง และภาพที่ใส่จะใช้ทั้งในเว็บและภาพแชร์

## ขอบเขตและความเป็นส่วนตัว

คำอ่านเป็นเนื้อหาแยกตามไพ่และหัวข้อ ไม่ใช่ AI สนทนาและไม่วิเคราะห์คำถามแบบเฉพาะบุคคล คำถามมีไว้บันทึกความตั้งใจ ยังไม่มีบัญชี/การซิงก์ข้ามเครื่อง LINE OA การแจ้งเตือน การชำระเงิน หรือโหราศาสตร์วันเกิด การล้างข้อมูลเว็บไซต์จะลบประวัติ ไพ่รายวัน และสตรีค จึงไม่ใช่การจำกัดสิทธิ์รายวันฝั่ง server

ห้องสมุดไพ่เป็นเนื้อหาภายในแอป ยังไม่ได้ทำหน้า SEO แบบแยก URL/SSR ทั้ง 78 ใบ ควรทำเป็นงานต่อไปพร้อมระบบเนื้อหาและ domain จริง ไม่ควรอ้างว่าเวอร์ชันนี้มี SEO articles ที่ค้นเจอแยกหน้าแล้ว

## GitHub Pages

ผู้ใช้เลือกเผยแพร่เว็บทดลองผ่าน GitHub Pages ของ `kharnsak/tarot` จึงเพิ่ม workflow `.github/workflows/pages.yml` ให้ทดสอบและ build เมื่อ push ไป `main` แล้วเผยแพร่ด้วย GitHub Pages Actions

ต้องเปิดใช้ Pages ของ repository โดยเลือก Source เป็น **GitHub Actions** ก่อน workflow จะ deploy ได้ การ build สำหรับ Pages ใช้ `npm run build -- --base=/tarot/` เพื่อให้ JavaScript, CSS, favicon และภาพไพ่โหลดจากเส้นทาง `/tarot/` อย่างถูกต้อง ส่วนการพัฒนาในเครื่องยังใช้ `/` ตามปกติ

ลิงก์ปลายทางที่คาดหมายคือ `https://kharnsak.github.io/tarot/` — ต้องรอผล deploy และตรวจลิงก์จริงก่อนถือว่าออนไลน์ การมี workflow ในโปรเจกต์ไม่ได้ยืนยันว่า deploy สำเร็จแล้ว

ไพ่ใช้เพื่อความบันเทิงและการไตร่ตรอง ไม่ใช่ข้อเท็จจริงเกี่ยวกับอนาคต ความคิดของผู้อื่น หรือคำแนะนำทางการแพทย์ การเงิน และกฎหมาย

## โครงสร้าง

- `src/App.tsx` หน้าแรก ห้องสมุด ประวัติ แชร์ และความเป็นส่วนตัว
- `src/ReadingFlow.tsx` ขั้นตอนตั้งคำถาม → สับ → เลือก → พลิก → อ่าน
- `src/tarot.ts`, `src/minor-meanings.ts` ข้อมูลไพ่และคำอ่านภาษาไทย
- `src/storage.ts` การสุ่ม วันตามเวลาไทย ประวัติ และสตรีค
- `src/art.tsx` ภาพสำรอง SVG และการโหลดชุดไพ่จริง
- `src/share.ts` สร้างภาพ PNG ในเครื่อง
- `src/Dialog.tsx` dialog พร้อม focus trap, Escape และคืน focus
- `src/styles.css` ธีมและ responsive layouts
