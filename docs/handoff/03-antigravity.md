# ใบสั่งงาน: ANTIGRAVITY (UI/UX และแอนิเมชัน)

Repo: React 19 + Vite + TS + `motion` (Framer Motion v12). อ่าน `docs/handoff/00-README.md` ก่อน **แก้เฉพาะไฟล์ในคอลัมน์ Antigravity** ข้อมูลไพ่และข้อความให้ import จาก `src/tarot.ts` / `content/ui.json` ห้าม hardcode
ทำบนมือถือก่อน (390×844) แล้วค่อยขยายไปเดสก์ท็อป ใช้ browser agent เปิดดูและแคปจอทุกหน้า

## ปัญหาตอนนี้ (จากเจ้าของ)
สีมืดหม่น ไม่มีพลัง / ฟอนต์แข็ง ไม่ทันสมัย / ตอนเปิดไพ่แค่กางไพ่แล้วกด ดูแข็ง / UX งง ไม่ดึงดูด

## Design direction: "Ivory & Gold Foil" สะอาดแบบ Apple แต่ยังมีความลึกลับ
- **พื้นหลัง:** ขาวงาช้าง `#F7F4EE` ไล่เฉดอ่อนมาก, มีโหมด "กลางคืน" เป็นดำหมึก `#0D0D0F` (ไม่ใช่ม่วงหม่น)
- **ตัวหนังสือ:** `#111111` / รอง `#6B6660`
- **ทอง:** `#B8913A` → ไล่เป็น `#E9CF8A` ใช้ทำเส้น, ไอคอน, หลังไพ่ (ใส่ gradient + shimmer ให้เหมือนฟอยล์จริง)
- **Glass:** การ์ด `rgba(255,255,255,0.55)` + `backdrop-filter: blur(20px) saturate(140%)` + ขอบ 1px ขาวโปร่ง + เงานุ่ม
- **หลังไพ่:** พื้นดำด้าน ลายเส้นทองบาง (พระจันทร์ + ดาว แบบเรขาคณิต) ตัดกับพื้นขาว จะเด่นสุดในจอ
- **ฟอนต์:** ไทยใช้ `Anuphan` (โมเดิร์น นุ่ม อ่านง่าย) ทั้งหัวและเนื้อ หัวข้อหนัก 600, เนื้อ 400 / อังกฤษหรือตัวเลขไพ่ใช้ `Cormorant Garamond` italic เท่านั้น ลบ Noto Serif Thai ออก (`npm i @fontsource/anuphan`)
- จังหวะแบบ Apple: ตัวหนังสือใหญ่ พื้นที่ว่างเยอะ หน้าละ 1 เรื่อง ใช้ scroll-reveal นุ่มๆ (spring stiffness ~120, damping ~20)

## Flow ใหม่ (ลดเหลือ 3 จังหวะ ไม่งง)
1. **หน้าแรก:** ทักตามเวลา + การ์ด "ไพ่ประจำวัน" ใหญ่เด่นด้านบน (ปุ่มเดียว) → ด้านล่างเป็นชิปหัวข้อ: ความรัก · เขาคิดยังไง · งาน · เงิน · Yes/No · ถามเอง → แถบสตรีค 🔥 เล็กๆ
2. **ตั้งจิต:** พิมพ์คำถาม (มีตัวอย่างให้กด) → กดค้างที่สำรับเพื่อ "สับ" (มีสั่นเบาๆ ด้วย `navigator.vibrate` ถ้ามี)
3. **หยิบไพ่ (ไฮไลต์หลัก):**
   - สำรับวางซ้อนกลางจอ สับด้วยแอนิเมชัน riffle จริง (แบ่ง 2 กอง แล้วสลับเข้าหากัน) จากนั้นไพ่กางเป็นพัดโค้ง
   - **ลากนิ้ว/เลื่อนผ่านพัด** ใบที่อยู่ใต้นิ้วจะยกขึ้น (เหมือนนิ้วไล่หยิบ) → ปล่อยนิ้วหรือแตะ = หยิบใบนั้น ลอยขึ้นไปวางที่ช่องของตำแหน่งสเปรด
   - มีภาพ "มือ" แบบเส้นทองบางๆ (SVG) ค่อยๆ เลื่อนลงมาหยิบไพ่ตอนครั้งแรก เพื่อสอนวิธีใช้ แล้วหายไป
   - **เปิดไพ่:** หมุน 3D แกน Y (perspective 1200px) + มีแสงวิ้งวาดผ่านหน้าไพ่ + ฝุ่นทองกระจายเล็กน้อย ใบละ ~700ms
   - เคารพ `prefers-reduced-motion` (ถ้าเปิดไว้ ให้ใช้แค่ fade)
4. **ผลทำนาย:** ไพ่ใหญ่ → คำคม 1 บรรทัด (ตัวใหญ่) → เนื้อหาแยกตามตำแหน่ง → บรรทัดเฉพาะวันเกิด (ถ้ามี) → ปุ่ม **"แชร์ผล"** และ **"ถามต่อ"** (โชว์ชิปคำถามต่อ 3 อัน)
5. **ภาพแชร์** (`src/share.ts`): canvas 1080×1920 สำหรับสตอรี่ + 1080×1350 สำหรับฟีด พื้นขาวงาช้าง ไพ่ตรงกลางมีเงา คำคมตัวใหญ่ ชื่อเว็บเล็กๆ ด้านล่าง ใช้ Web Share API ถ้าไม่ได้ให้ดาวน์โหลดแทน

## ห้าม
gradient ม่วง-ชมพูแบบ AI, ใส่ glow ทุกอย่าง, ใช้อีโมจิเป็นไอคอน (ใช้ lucide), ทำปุ่มเกิน 2 ปุ่มต่อหน้าจอ
